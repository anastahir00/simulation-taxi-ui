# Simulation Taxi – UI/UX Panel Showcase

This repository contains UI designs created for the *Simulation Taxi* game during my internship at IDEO Spaces. Built in Unity using C#, it includes:

- Main Menu
- Car Selection
- Level Selection
- Loading Screen
- Gameplay Panel
- Pause Menu
- Sound Settings
- Quit Panel

These screens were developed with a focus on clean user experience and gameplay flow.
